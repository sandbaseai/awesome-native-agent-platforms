# Contributing

Thanks for improving this list.

## What Fits

Submissions should be relevant to production AI agent infrastructure, including:

- Agent runtimes
- Sandboxed execution
- Browser infrastructure
- Model routing
- Tool and protocol integration
- Agent observability and operations
- Developer platforms for production agent apps

## Entry Format

```markdown
### [Name](https://example.com)

Short neutral description.

- Key capability
- Key capability
- Useful for: primary use case
```

## Guidelines

- Prefer neutral descriptions over marketing copy.
- Include the official website or repository.
- Avoid duplicate entries.
- Keep entries concise.
- Do not submit tools that are only generic prompt libraries, model lists, or unrelated AI directories.
